# コピーテンプレート

[機能一覧に戻る](../../README.md#主な機能)

集計結果を、Discord への貼り付けなど用途に合わせた任意のフォーマットでクリップボードへコピーできます。名前、ダメージ、DPS、会心率などのプレースホルダーを組み合わせて出力内容を決めます。

設定したテンプレートは、メイン画面のコピーと計測結果画面のコピーで使えます。必要な列だけを短く出力したい場合や、共有用の見た目を揃えたい場合に便利です。

## 使い方

1. 設定パネルのコピーテンプレートを開きます。
2. プレースホルダーを使って出力形式を入力します。
3. メイン画面または結果画面のコピーを押します。
4. 貼り付け先で内容を確認します。

利用できるプレースホルダーは設定欄の説明に表示されます。テンプレートを変更したら、実際にコピーして改行や空白も確認してください。
