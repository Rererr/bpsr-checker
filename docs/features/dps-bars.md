# 行バーの表示方式

[機能一覧に戻る](../../README.md#主な機能)

DPS 一覧の各行に表示する横バーの基準を、4種類から選べます。

- トップ比: 最大 DPS を右端にする既定の表示
- 全体比: パーティ合計に対する貢献割合
- 固定基準: 指定した基準 DPS を右端にし、直近の平均 DPS を表示
- 自分基準: 自分を50%位置に固定し、他プレイヤーを自分との相対比で表示

バーの濃度は「なし・控えめ・くっきり」から選べます。幅の変化を滑らかにするアニメーションもありますが、CPU 使用率が少し上がるため既定では OFF です。

## 使い方

1. 設定パネルのバー表示方式を選びます。
2. 固定基準では基準 DPS と平均秒数を入力します。
3. 見やすさに合わせてバー濃度とアニメーションを選びます。
