# キャラ指定

[機能一覧に戻る](../../README.md#主な機能)

自キャラの自動判定が外れたときに、設定パネルから自キャラの UID を直接入力するか、現在のプレイヤー候補から選んで固定できます。名前は名前キャッシュから解決して表示します。

自キャラの判定を固定すると、自分強調、自己ベスト、ステータス表示など、自分を基準にする機能の対象を安定させられます。誤判定のまま使い続ける必要はありません。

## 使い方

1. 設定パネルの自キャラ UID欄を開きます。
2. UIDを直接入力して確定するか、候補ボタンから自分を選びます。
3. DPS 一覧で自分の強調表示と名前を確認します。
4. 固定を解除するときは UID欄をクリアします。

自分の名前が Player #XXXX のままの場合は、読み込みが入る移動や再ログインで名前情報が届くことがあります。過去に観測した UID は30日間の名前キャッシュから復元されます。
