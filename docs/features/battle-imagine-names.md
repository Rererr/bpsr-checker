# バトルイマジン名の表示

[機能一覧に戻る](../../README.md#主な機能)

DPS 一覧の名前列に、プレイヤーが装備しているバトルイマジンをレベル（凸数）付きで表示します。実装備の2枠は名前列テンプレートの {imagine}、ロールスキル枠の簡易版は {roleSkill} で個別に配置できます。

名前列が狭い場合は、ロールスキル、イマジン、プレイヤー名の順に省略されます。プレイヤー名は最後まで残るため、狭いオーバーレイでも識別できます。設定から開く専用編集ウィンドウでは、表示名の上書きと特定イマジンの非表示を指定できます。これらは表示だけに適用され、検知や記録データは変わりません。

## 使い方

1. 設定パネルの名前列テンプレートに {imagine} または {roleSkill} を残します。
2. 表示名を変えるときは、設定のイマジン名編集を開きます。
3. 名前列が狭いときは、ウィンドウを広げるか、テンプレートから不要なトークンを外します。

自分の装備はマップ移動ごと、周囲のプレイヤーはダンジョン読込やボス部屋切替などのタイミングで検知します。
