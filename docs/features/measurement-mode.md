# 計測モード

[機能一覧に戻る](../../README.md#主な機能)

模擬戦やボス練習向けに、計測開始から固定時間で集計するモードです。既定は180秒で、設定から計測時間を変更できます。

計測中および結果画面の DPS は、計測開始からの固定時間を分母にします。攻撃を止めていた時間も含めるため、ゲーム内の計測機能と同じ条件で比較できます。結果画面ではキャラクター別・スキル別の DPS 推移、スキル内訳の円グラフ、総ダメージを確認できます。

計測の時計は、計測ボタンを押した瞬間ではなく**自分が最初に行動した瞬間**から回り始めます。押してから構え直すまでの時間や、周囲で進行中の他プレイヤーの戦闘は分母に入りません。

自分の最高記録は計測時間ごとに保存されます。同じ時間設定で記録を更新すると、結果画面に新記録が表示されます。TOP3 は金・銀・銅で強調され、日時入りの結果画像を画像コピーでクリップボードへ送れます。

## 計測する範囲を絞る

設定の戦闘欄に、計測中だけ効く絞り込みが2つあります。どちらも既定は OFF で、通常の表示は変わりません。

- **計測を自分の記録のみにする**：計測中、与ダメージ・回復・被ダメージのすべてを自分の記録だけにします。共有の木人のように同じ相手を他のプレイヤーも攻撃している場所では、自分の火力が総ダメージの数パーセントしか占めないことがあります。この設定はそれを切り分けるためのものです。他のプレイヤーのデータを捨てているわけではないので、設定を戻せば元の表示に戻ります。
- **計測を最初に攻撃した敵のみにする**：計測中、自分が最初にダメージを与えた相手への攻撃だけを集計します。単体の相手を測るとき用です。複数の相手を同時に攻撃する計測では、最初の1体ぶんしか集計されません。

絞り込みが効いていた計測は、履歴の一覧と結果画像の透かしに条件が入ります。条件付きの数値は通常の計測と直接比較できないためです。自己ベストも条件ごとに別枠で記録されます。

絞り込みの条件は計測を開始した時点のものが最後まで使われます。走行中は該当する設定を変更できません。

## 使い方

1. 設定で計測時間と、必要なら絞り込みを決めます。
2. メイン画面の計測を押します。自分が最初に行動した時点で計測が始まります。
3. 終了後、結果画面でプレイヤーやスキルを選択します。
4. 画像コピーで結果画面を共有します。
