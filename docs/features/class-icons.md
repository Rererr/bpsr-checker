# 職業アイコン表示

[機能一覧に戻る](../../README.md#主な機能)

DPS 一覧の名前列に、職業アイコンをロール色で表示します。アタッカー、タンク、ヒーラーを色で区別でき、名前を読む前にパーティ構成を把握できます。

名前列テンプレートの {classIcon} がアイコンの位置です。既定では名前の前に表示され、トークンを外すと非表示になります。起動直後など職業情報がまだ届いていない場合は、観測できたスキルから推定されます。

## 使い方

1. 設定パネルの名前列テンプレートに {classIcon} を入れます。
2. アイコンを名前の後ろへ置きたい場合は、テンプレート内の位置を移動します。
3. 文字だけにしたい場合はトークンを削除します。
