# オーバーレイのウィンドウ操作

[機能一覧に戻る](../../README.md#主な機能)

ゲーム画面の上で使うための、常に最前面、クリックスルー、タスクバー・タスクトレイの切り替えをまとめた機能です。メイン画面と各オーバーレイは縁をドラッグしてリサイズできます。

タイトルバーのボタンから最小化と最前面ピンを切り替えられます。既定では最小化するとメイン画面とオーバーレイがタスクトレイへ退避します。タスクバーに常駐を ON にすると、各ウィンドウが個別のタスクバーボタンになります。

クリックスルーを ON にすると全ウィンドウが背後のゲームへマウス操作を通します。解除はタスクトレイメニューから行います。オーバーレイ右上の × は設定の表示トグルと連動します。

## 使い方

1. タイトルバーのピンで最前面表示を切り替えます。
2. 画面を操作するときは、タスクトレイからクリックスルーを ON にします。
3. 解除するときもタスクトレイメニューを使います。
4. タスクバーで個別に扱いたい場合は設定でタスクバーに常駐を ON にします。
