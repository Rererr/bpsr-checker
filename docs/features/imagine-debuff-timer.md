# イマジンデバフタイマー

[機能一覧に戻る](../../README.md#主な機能)

ティナ、アルーナ、タータ、バジリスク、ガトグリフの免疫デバフ残時間を、独立したオーバーレイで表示します。イマジンごとに色が異なるリングで、誰のどのデバフが残っているかをすばやく確認できます。

既定では DPS 一覧と同期し、表示するプレイヤーと並び順を自動追従します。同期を OFF にすると、ピンで手動追加した相手だけを表示できます。表示するイマジン種類は個別に選択でき、行を詰める密表示にも対応します。

## 使い方

1. 設定でイマジンデバフタイマーを ON にします。
2. DPS 一覧のピンで追跡するプレイヤーを切り替えます。
3. DPS 一覧との同期を OFF にした場合は、ピンと一括クリアで表示対象を管理します。
4. パーティ構成に合わせて表示するイマジンを選びます。
